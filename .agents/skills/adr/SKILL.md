# 目的

次の実装に入る前に、チャットで決まった方針・切った案・理由を `docs/adr/` に残す。

# ルール

- 本文は日本語
- チャットで決まったことだけ書く。決めていないことを補完・捏造しない
- 技術スタックが未決なら、未決のままにする。埋めない
- このスキルは ADR ファイルの作成に限る。実装・commit・push・PR・issue 作成はしない
- 既存の ADR を勝手に書き換えない。新しい決定は新しいファイルにする

# ファイル

置き場所: `docs/adr/`

ファイル名: `{連番}-{決定内容が分かる日本語}.md`

- 連番は 2 桁（`01`, `02`, …）。既存の最大番号の次を使う
- 例: `01-公開プロフィールの規模は来場者数にする.md`
- ディレクトリが無ければ作る

連番の確認:

```bash
ls docs/adr/*.md 2>/dev/null
```

# 本文の形

```markdown
# {決定の一文}

## 決定

チャットで決めた方針。

## 切った案

検討したが採用しなかった案。無ければ「なし」。

## 理由

その方針にした理由。チャットに出たものだけ。
```

# 手順

1. `docs/adr/` の既存ファイルから次の連番を決める
2. 会話から「決まったこと / 切った案 / 理由」だけ抜き出す。不足なら聞いて、ファイルはまだ書かない
3. 上記の形で 1 ファイル書く
4. 書いたパスをユーザーに伝える
