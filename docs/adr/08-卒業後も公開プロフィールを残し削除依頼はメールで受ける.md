# 卒業後も公開プロフィールを残し、削除依頼はメールで受ける

## 決定

卒業後も公開プロフィールは残す。後輩が参照できるようにするためである。公開と非公開の切り替えは置かない。

削除依頼の窓口は、今はアプリ内に急がない。画面のフッターに、運営者自身のメールアドレスを置き、そこへ依頼を送ってもらう。削除依頼を送るフォームは、あとで作る。

具体のメールアドレスと、フッターをどの画面に置くかは未決である。

## 切った案

- 卒業後に公開をやめる、または期限が来たら消す。
- 公開と非公開の切り替えを Must にする。登録した経験を他人に見せず、自分だけで管理する運用を Must にする。
- 削除依頼のフォームを、今すぐアプリに置く。

## 理由

このアプリケーションの中心は、自分の経験を 1 つの URL で共有できることである。公開と非公開を切り替えて、他人に見せずに管理する運用は、今の Must ではない。

卒業後もデータが残っていれば、後輩の学生が参考にできる。

削除の依頼先は必要だが、アプリ側のフォームを急がなくてよい。まずはフッターのメールアドレスで受け、フォームはあとで足す。
