# 公開プロフィールの URL は /public/:username にする

## 決定

公開プロフィールの URL は `/public/:username` にする。

ユーザー名の長さは 3 文字以上 25 文字以下とする。使える文字は ADR-03 のまま、小文字英字と数字のみである。

ADR-06 の、旧ユーザー名から現在のユーザー名へのリダイレクトは、このパスの下で行う。

## 切った案

- 予約語を定義し、公開 URL を `/{username}` のままにする。
- 公開 URL を `/u/mitti` のような別の接頭辞にする。

## 理由

公開 URL が `/{username}` だと、`login` や `onboarding`、`dashboard` と同じ階層になる。その名前を登録できても、URL を開くと公開プロフィールではなく固定の画面になる。

`/public/:username` にすると、公開プロフィールだと分かり、画面用のパスと重ならない。

ユーザー名の最大は 25 文字とする。長さを変えても、DB で username を等価検索する速度は変わらない。上限の標準はなく、他サービスは X が 15、Reddit が 20、Instagram と YouTube が 30、GitHub が 39 である。日本人の名前（ローマ字）は平均 15 文字で、重複を避ける数字 4 桁を足した長さが収まるよう、最大は 25 文字にする。下限は 3 文字である。
