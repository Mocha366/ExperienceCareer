# 自分のタイムラインに経験の削除ボタンを出す

## 決定

ログイン中の本人が、自分のタイムラインを開いているとき、各経験に削除ボタンを出す。これは Must である。削除すると、その経験は公開プロフィールのタイムラインから消える。これは ADR-03 のとおりである。

同じ場所に出す編集ボタンは Should である。余裕があるときに足す。経験を登録・編集できること自体は、Must のままである。

## 切った案

- 経験の削除を Must に入れない。
- タイムライン上の編集ボタンも、今回の Must に含める。

## 理由

経験は保存した時点で公開される。誤った内容や、載せたくない経験を保存すると、タイムラインから取り下げられない。

編集は、タイムライン上のボタンとしては後回しでよい。登録と編集の機能自体は残す。
